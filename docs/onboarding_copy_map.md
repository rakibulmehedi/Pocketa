# Onboarding Copy Map - ARB Keys & Tone Guidelines

## Tone Guidelines
- **Empowering**: "You're in control", "Your data stays yours"
- **Confident**: "Starting today", "You've got this"
- **Friendly**: "See you tomorrow?", "With friends"
- **Clear**: Short, actionable phrases
- **Inclusive**: Gender-neutral, culturally sensitive
