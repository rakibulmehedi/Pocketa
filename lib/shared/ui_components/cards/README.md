# Cards

Card components for organizing content sections.

## Components

- **SectionCard** - Consistent card with header for content sections
- **ResponsiveGrid** - Enhanced grid layout that adapts to screen sizes
- **InteractiveCard** - Interactive card with micro-interactions
- **PersonalizationCard** - Specialized card for personalization options

## Usage

```dart
import 'package:pocketa/shared/ui_components/cards/cards.dart';

SectionCard(
  title: 'Settings',
  subtitle: 'Manage your preferences',
  children: [/* your content */],
)
```
