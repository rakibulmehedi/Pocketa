# Lists

List components for displaying data efficiently.

## Components

- **AppListTile** - Premium interactive list tile
- **OptimizedListView** - Performance-optimized list view
- **OptimizedGridView** - Performance-optimized grid view

## Usage

```dart
import 'package:pocketa/shared/ui_components/lists/lists.dart';

AppListTile(
  title: Text('Item Title'),
  subtitle: Text('Item subtitle'),
  trailing: Icon(Icons.arrow_forward),
  onTap: () => handleTap(),
)
```
