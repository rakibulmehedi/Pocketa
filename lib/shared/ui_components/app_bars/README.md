# App Bars

App bar components with premium fintech design.

## Components

- **CustomAppBar** - Enhanced app bar with smart back/menu handling
- **CustomSliverAppBar** - Collapsible sliver app bar with flexible space

## Usage

```dart
import 'package:pocketa/shared/ui_components/app_bars/app_bars.dart';

CustomAppBar(
  title: 'Dashboard',
  subtitle: 'Welcome back',
  trailingPillText: '৳ 12,450',
)
```
