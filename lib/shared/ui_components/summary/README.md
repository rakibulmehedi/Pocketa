# Summary

Summary components for displaying financial data.

## Components

- **SummaryHeader** - Summary header with gradient background
- **SummaryRow** - Individual summary row component

## Usage

```dart
import 'package:pocketa/shared/ui_components/summary/summary.dart';

SummaryHeader(
  income: 50000,
  expense: 30000,
  netAmount: 20000,
  currency: '৳',
)
```
