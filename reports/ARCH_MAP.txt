POCKETA Architecture Map (high-level)

app (MaterialApp.router)
  -> core/routing/router.dart (GoRouter with onboarding redirect)
  -> core/locale/* (Locale provider + l10n)
  -> core/theme/* (AppTheme)
  -> core/db/hive_bootstrap.dart (Hive init + safe open + compaction)

core/
  analytics/analytics_service.dart  (AnalyticsService, batching wrapper)
  errors/{exceptions.dart,failure.dart,exception_mapper.dart}
  result/result.dart                (Ok/Err result type)
  sync/{sync_queue.dart,sync_remote.dart,supabase_stub.dart}
  utils/*, ui/*, responsive/*       (UI utilities and layouts)

features/
  categories/
    domain/{entities,repositories}
    data/{models,category_repo_impl.dart}
    presentations/{viewmodels,widgets}

  wallets/
    domain/{entities,usecases,repositories}
    data/{models,wallet_repo_impl.dart}
    presentations/{viewmodels,widgets}

  transaction/
    domain/{entities,usecases,repositories}
    data/{models,mappers,transaction_repo_impl.dart}
    presentation/{pages,viewmodels,widgets}

  dashboard/ (presentation)
  onboarding/ (presentation)

shared/
  widgets/{buttons,app_bar,section_card,input/*}

External deps:
  Riverpod, Hive, GoRouter, intl, logger, freezed/json_serializable

Data flow (simplified):
UI (widgets) -> Riverpod Providers (controllers/usecases) -> Repositories -> Hive (offline store)
                                                 |
                                                 -> SyncQueue (background send to remote)
